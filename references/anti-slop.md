# Anti-slop web guidance

Use this as a review lens, not as a universal style ban. In `guided` and
`creative`, a deliberate exception is acceptable when its reason is recorded.

## Common failure patterns

- centered hero with an oversized generic gradient and no evidence;
- three equal feature cards used when the content has a sequence or hierarchy;
- fake terminal, dashboard or analytics UI made from decorative rectangles;
- random nodes, circuit traces, particles or glowing “AI” brains;
- fabricated customer logos, metrics, status dots or “trusted by” signals;
- multiple unrelated icon families or arbitrary corner radii;
- motion that changes position without clarifying causality or focus;
- a page that changes theme, accent or density without a content reason;
- text embedded inside generated imagery instead of real HTML;
- visual polish applied before claims, hierarchy and mobile behavior are stable.

## Positive replacement

Replace the cliché with an evidence-bearing relation: real task state,
physical-world context, labeled transformation, source-backed metric,
lineage, boundary, failure mode, or explicit action path.

## Review questions

1. Can the page's primary judgment be stated without mentioning the visual style?
2. Does every prominent object explain a claim, relation, action or hierarchy?
3. Does the page still make sense in grayscale and with media removed?
4. Is the design distinct because of ArcheBase's message and evidence, not only because of effects?
